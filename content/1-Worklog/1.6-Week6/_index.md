### Week 6 Objectives:

* Learn fundamental database concepts and database management systems.
* Understand the differences between relational databases (RDBMS) and NoSQL databases.
* Learn about OLTP and OLAP processing models.
* Explore AWS database services and their use cases.
* Practice creating, connecting, backing up, and restoring databases using Amazon RDS.
* Learn the migration process from Oracle databases to Amazon Aurora PostgreSQL.

### Week 6 Achievements:

* Understand fundamental database concepts and database management mechanisms.
* Understand the differences between RDBMS and NoSQL databases.
* Gain knowledge of major NoSQL database models including Document, Key-Value, Wide-Column, and Graph databases.
* Understand OLTP and OLAP architectures and their use cases.
* Understand the role of Data Warehouses in analytical workloads.
* Gain knowledge of Amazon RDS architecture and management capabilities.
* Understand key Amazon RDS features such as Read Replica, Multi-AZ deployment, Automatic Failover, and Storage Auto Scaling.
* Understand Amazon Aurora architecture and advanced database features.
* Learn how Amazon ElastiCache improves database performance through caching.
* Understand Amazon Redshift architecture for large-scale analytical processing.
* Gain knowledge of database migration strategies from Oracle to Amazon Aurora PostgreSQL.
* Successfully complete hands-on labs including:

  * Creating databases on Amazon RDS
  * Connecting applications to databases
  * Performing backup and restore operations
  * Schema conversion
  * Data migration
* Be able to select and implement suitable AWS database services for different application scenarios.
