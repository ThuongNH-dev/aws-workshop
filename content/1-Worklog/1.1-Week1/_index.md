### Achievements in Week 1:

* Understand the basic concepts of cloud computing and the role of AWS in deploying and managing cloud infrastructure.

* Gain knowledge of major AWS service categories:

  * Compute
  * Storage
  * Networking
  * Database
  * Security & Management

* Connect and collaborate with FCAJ community members for learning and knowledge sharing.

* Successfully create and configure an AWS Free Tier account while understanding Free Tier usage limitations.

* Become familiar with AWS Management Console:

  * Navigate and search for AWS services
  * Manage basic AWS resources
  * Monitor AWS service status

* Install and configure AWS CLI on a local computer:

  * Configure Access Key and Secret Key
  * Set default AWS Region
  * Verify AWS CLI connection with AWS account

* Use AWS CLI to perform basic operations:

  * Check AWS CLI configuration
  * List AWS Regions
  * Interact with basic AWS services
  * Manage key pairs and simple resources

* Learn how to use AWS Budgets to:

  * Track AWS service costs
  * Create budget alerts
  * Control resource usage and avoid unexpected charges

* Understand the role of AWS IAM in access management and security:

  * Create IAM Users and Groups
  * Attach Policies for permission management
  * Secure AWS account access effectively

* Be able to combine AWS Console and AWS CLI for more efficient AWS resource management during hands-on practice.
