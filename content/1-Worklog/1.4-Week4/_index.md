### Week 4 Achievements:

* Gained an understanding of Amazon S3 object storage architecture and how data is organized using Buckets and Objects.

* Learned the key features of Amazon S3:

  * Object Key
  * Multipart Upload
  * Event Notification
  * Access Point

* Understood the different Amazon S3 storage classes:

  * S3 Standard
  * S3 Standard-IA
  * S3 Intelligent-Tiering
  * S3 One Zone-IA
  * Glacier
  * Deep Archive

* Learned how Lifecycle Policies can be used to optimize storage costs.

* Learned how to host a static website using Amazon S3.

* Understood the purpose and use cases of CORS in web applications.

* Learned different methods of controlling access to Amazon S3 resources:

  * ACL
  * Bucket Policy
  * IAM Policy

* Understood the role of VPC Endpoints in accessing Amazon S3 through the AWS private network.

* Learned how Versioning helps recover data from accidental deletion or overwrites.

* Explored large-scale data migration solutions:

  * Snowball
  * Snowball Edge
  * Snowmobile

* Understood hybrid storage architectures using AWS Storage Gateway:

  * File Gateway
  * Volume Gateway
  * Tape Gateway

* Learned important Disaster Recovery concepts:

  * Recovery Time Objective (RTO)
  * Recovery Point Objective (RPO)

* Explored AWS disaster recovery strategies:

  * Backup & Restore
  * Pilot Light
  * Low Capacity Active
  * Full Capacity Active

* Learned how to manage and monitor backup operations using AWS Backup.

* Successfully completed hands-on activities including:

  * Creating an S3 Bucket
  * Uploading data to Amazon S3
  * Hosting a static website on S3
  * Creating a Storage Gateway
  * Creating a Backup Plan
  * Verifying backup operations

* Developed the ability to select appropriate storage, backup, and disaster recovery solutions for different AWS deployment scenarios.
